# KOTOHA: LOST CODE

JSON-driven story game engine prototype.

## Structure

- `index.html` — game shell
- `css/` — presentation
- `js/` — runtime / scenario engine
- `data/scenarios/` — story data
- `assets/characters/` — character sprites and expressions
- `assets/backgrounds/` — background images
- `assets/cg/` — event CGs
- `assets/ui/` — UI assets
- `assets/audio/` — BGM / SE

Scenario files are data-driven so story content can be expanded without rewriting the core engine.
