# Scenarios

Story files are JSON. Add chapters/events here without changing the core engine.

Available commands in the current prototype:

- `background` — change background image
- `character` — show/move a character sprite
- `removeCharacter` — remove a character
- `dialogue` — show dialogue
- `choice` — show branching choices
- `image` / `clearImage` — show or clear event image
- `wait` — pause for a duration
- `effect` — visual effect (currently `flash`)
- `label` / `goto` — jump within the scenario
